## Ilia L. Rasskazov

Computational physicist. I build simulation software that other engineers make
decisions with.

At **Tandem PV** I develop a new class of *bankable* simulation software for
perovskite–silicon tandem modules — physics-based models calibrated on outdoor field
data and built to survive independent third-party technical due diligence. Before
that, large-scale electromagnetic simulation on HPC at **KLA** and inverse design of
manufacturable coatings at **SunDensity**.

**49 papers · 1,187 citations · h-index 21 · 200+ manuscripts reviewed**

### Things I've built

**[multilayer.app](https://multilayer.app)** — thin-film optics platform on a
transfer-matrix core, with a replication engine that recomputes spectra from published
papers and scores reproduction fit against digitized curves (span-normalized RMSE with a
maximum-deviation guard). An automated answer to *does this simulation actually reproduce
the literature?* · `Python · FastAPI · React · Pyodide/WASM`

**[STRATIFY](https://github.com/<username>/stratify)** — open-source package for
electromagnetic scattering by multilayered spheres. *OSA Continuum* **3**, 2290 (2020).
58 citations; adopted by the light-scattering community as working tooling. · `MATLAB`

**[iliarasskazov.com](https://iliarasskazov.com)** — my site, generated from two YAML
files by a 150-line build script, with a Crossref resolver that fills in DOIs by title.
[source](https://github.com/<username>/website) · `Python`

### Research

Numerical simulation of continuum systems — electromagnetics, charge transport, thin-film
optics. Inverse design and adjoint optimization. Recent work applies physics-informed deep
learning to measurement inversion in infrared microspectroscopy
([arXiv:2605.22503](https://arxiv.org/abs/2605.22503)).

Associate Editor at the ResearchHub Foundation. 200+ manuscripts reviewed for Nature
Portfolio, ACS, Optica, Wiley, Elsevier and SAGE.
